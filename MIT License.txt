> **Astuce VS Code** : Pour créer un fichier prompt natif reconnu par Copilot, tu peux aussi utiliser la commande **`Chat: New Prompt File`** depuis la palette de commandes (`Ctrl+Shift+P`). VS Code le placera dans `.github/prompts/` avec l'extension `.prompt.md`[reference:15]. Tu pourras ensuite l'invoquer avec `/nom-du-prompt` dans le chat.
